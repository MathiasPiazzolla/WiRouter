Mi piace come progetto perché è utile e abbastanza ambizioso da imparare molte tecnologie senza diventare ingestibile.

Nome del progetto

Per ora lo chiamerei WiRouter (il nome si può cambiare in seguito).

Obiettivo

Creare un'applicazione Windows che trasformi un PC in un router Wi-Fi intelligente.

Non sarà semplicemente un pulsante che attiva l'Hotspot di Windows, ma un vero pannello di gestione con funzionalità avanzate.

Stack tecnologico

Backend

Go (ultima versione stabile)
Accesso alle API Windows
Goroutine per monitoraggio in tempo reale
API REST locale (opzionale)

Frontend

Wails (Go + HTML/CSS/JavaScript) per un'interfaccia moderna
oppure
Fyne per una GUI completamente in Go.

Io propendo per Wails: offre un aspetto più moderno e una migliore esperienza utente.

Un aspetto tecnico importante

La sfida principale non sarà Go, ma l'integrazione con Windows. Le API per gestire hotspot e condivisione della connessione sono meno moderne rispetto ad altre parti del sistema e richiedono di lavorare con COM, servizi di Windows e privilegi amministrativi. Una volta realizzato questo livello di integrazione, il resto (GUI, monitoraggio, impostazioni e statistiche) sarà relativamente lineare.

Penso che questo possa diventare un progetto open source interessante: una sorta di alternativa moderna e gratuita al Mobile Hotspot di Windows, con molte più funzionalità e un'interfaccia curata.
